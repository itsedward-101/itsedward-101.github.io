AI Customer Support Performance Dashboard

Interactive Power BI analytics to pinpoint where AI support excels, where it breaks down, and how performance shifts by region, category, and language.

Personal Project / Independent Analysis

4 drill-down levels
Power BI multi-page dashboard
Kaggle real support data

The Problem

As businesses adopt AI in customer support, understanding where these systems succeed and fail becomes critical. Poor AI performance in certain scenarios directly harms customer experience. This project analyzes real-world AI customer support data to identify performance gaps and uncover opportunities for improvement.

Dataset: Kaggle — real customer support interaction data.

Objective

  • Evaluate AI customer support performance across segments
  • Identify where the AI model underperforms
  • Understand how performance varies geographically and by category
  • Provide actionable insights to guide model improvement

Solution — Power BI Dashboard

Built an interactive multi-page Power BI dashboard using a consulting-style drill-down framework:

  1. Level 1: Global Overview
  2. Level 2: Geographic (Country-Level) Segmentation
  3. Level 3: Category-Level Analysis
  4. Level 4: Subcategory Deep Dive

This structure lets users move from high-level trends to specific problem areas — mimicking a real consulting analysis workflow.

Dashboard Features

KPI metrics

AI failure rate, customer satisfaction rate, average resolution time, benchmark comparison.

Time-series trends

Ticket volume over time.

Category & subcategory

Breakdowns for structured diagnosis.

Geographic distribution

Global map view for regional patterns.

Language-based analysis

Performance across language contexts.

Dynamic country filtering

Selections propagate across all pages.

Analytical Techniques

  • DAX calculations: dynamic KPIs, conditional filtering, context-aware aggregations
  • Comparative analysis: failure rate vs benchmark, cross-country performance differences
  • Segmentation: geographic, category, and subcategory behavior
  • Trend analysis: recurring patterns and fluctuations over time

Key Findings

🌍

Regional performance gaps. AI performance is generally stable but varies across regions, suggesting localization gaps in the model.

⚠️

High-failure categories. Certain categories consistently show higher failure rates, indicating specific model limitations that need targeted fixes.

🔍

Subcategory concentration. Issues are concentrated in specific subcategories, enabling more precise and efficient improvements.

🌐

Language complexity. Multi-language usage in certain countries increases query complexity and impacts model performance.

📈

Recurring ticket patterns. Ticket volume trends show recurring patterns, suggesting shared systemic drivers rather than isolated incidents.

Future Opportunities

  • Deeper segmentation: language-level, intent classification, channel-based performance analysis
  • ML applications: predictive modeling for failure likelihood, classification of high-risk queries
  • Operational use: improving training data, enhancing localization, designing better escalation workflows
