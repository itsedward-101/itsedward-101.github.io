Predicting Video Game Commercial Success

Can pre-release attributes like platform, genre, and publisher predict whether a game becomes a hit ? before it launches?

1,878 games analyzed
4 ML models compared
80% accuracy achieved

The Problem

The video game industry is highly competitive, with studios facing major financial risk on every release. This project asked: can we predict whether a game will receive critical acclaim using only information available before launch ? platform, genre, publisher, and release year?

We defined a "hit" as any game scoring 75 or above on Metacritic (the "Generally Favorable" threshold), creating a binary classification target.

Dataset

Source
Kaggle -> Global Video Game Sales Dataset
Records
1,878 games (after cleaning)
Variables
13 original features
Target
is_hit -> 1 if Metacritic score -> 75, else 0
Class balance
74% hit, 26% non-hit
Key design decision: We deliberately removed post-launch data (global sales, regional sales, rank) to prevent the model from "cheating." Only pre-release features were used: Platform, Year, Genre, and Publisher.

Data Preparation

  1. Removed 31 rows with missing values -> 1,878 usable records
  2. Dropped leaky columns: Rank, Global Sales, Regional Sales, Review score
  3. Created binary target variable is_hit using Metacritic score -> 75
  4. One-hot encoded categorical variables: Platform, Genre, Publisher
  5. Applied 80/20 stratified train/test split
  6. Used class weighting to handle 74/26 imbalance across all models
  7. Applied 10-fold cross-validation for fair model comparison

4 Models Compared

Logistic Regression

Best variant: L1 + SMOTE + Class Weights

Accuracy: 74.9% -> AUC: 0.728

Note: Strong interpretability baseline

Decision Tree (my contribution)

Best variant: Class Weights

Accuracy: 70.6% -> AUC: 0.637

Note: Limited by single-tree overfitting

Winner

Random Forest

Best variant: GridSearchCV + Class Weights

Accuracy: 77.3% -> AUC: 0.756

Note: Best overall generalization

Naive Bayes

Best variant: SMOTE

Accuracy: 49.3% -> AUC: 0.679

Note: Weakest -> independence assumption violated

Random Forest with GridSearchCV selected as final model

Final Model Performance

80.3% Accuracy
83.8% Precision
91.0% Recall
87.3% F1 Score
0.813 AUC

Evaluated on held-out test set (20% of data). Model used 200 trees, max depth 20, balanced class weights, and square-root feature sampling.

What Drives a Hit Game?

📅

Release Year Most influential feature (importance score: 0.22). Newer games trend toward higher review scores.

🏆

Publisher Reputation ? Nintendo, THQ, Activision, and Electronic Arts are strong positive predictors.

🎮

Platform Ecosystem ? Wii, DS, and PlayStation platforms correlate strongly with hit status.

🎯

Genre Patterns ? Sports, Role-Playing, and Miscellaneous genres show higher hit rates.
